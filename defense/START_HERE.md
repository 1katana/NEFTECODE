# Материалы защиты

Презентация и DEMO_CHECKLIST перенесены из исходного submission. Полный код находится в соседней папке `../project`, а не в `project_code`.

1. Установить зависимости и запустить API по корневому README сборки.
2. Запустить интерфейс из `project/orchestrator/frontend/dist`.
3. Использовать сценарий показа из DEMO_CHECKLIST; все команды там выполнять из `project`.
4. Бенчмарк находится в `project/integration/dashboard/benchmark.html`.

README_original_package.md описывает старое расположение файлов и сохранён для справки. Старые копии кода, интерфейса и бенчмарка из submission исключены: актуальные находятся в project. Содержание презентации не редактировалось. Одинаковые PPTX сохранены в одном экземпляре; если исходные презентации отличаются, сохранены обе.
