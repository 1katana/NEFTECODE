# НИКИТА — ЛИМС

> **ЛИМС — лабораторная «истина» по качеству. Его роль в системе — давать контрольный факт для обучения и проверки моделей, а не потоковое состояние установки.**
> 

<aside>
🎯

**Главный вывод:** одна реальная лабораторная проба = одна target-строка. ЛИМС нельзя размножать на 10-минутную сетку и считать каждую строку отдельным наблюдением.

</aside>

## Роль ЛИМС в общей схеме

| Источник | Что показывает | Роль в модели |
| --- | --- | --- |
| **Телеметрия АВТ + 24-2000** | Как работала установка: температуры, давления, расходы, уровни | История технологического режима |
| **ПАК** | Оперативное качество: сера, D15 и др. | Оперативный сигнал / признак |
| **ЛИМС** | Редкие лабораторные пробы | **Ground truth качества / target** |

Связка для обучения:

```
режим процесса до отбора пробы
        ↓
технологический лаг
        ↓
лабораторный результат ЛИМС
```

**Не джойним ЛИМС с телеметрией строка-к-строке.** Синхронизация выполняется только по времени. Для каждой пробы нужно брать историю процесса **до момента отбора**, а не будущие значения.

### Что отсюда следует для ML

Для серы нужны две связанные задачи:

- **регрессия:** прогноз значения `Sulfur`;
- **классификация риска:** `P(Sulfur > 10 мг/кг)`.

Жёсткая граница для готового дизельного топлива: **S ≤ 10 мг/кг**.

## Кандидаты на target

В презентации зафиксированы отдельные целевые показатели:

- `Sulfur`;
- `T95`;
- `FlashPoint`;
- `D15`.

Каждый показатель должен обучаться как **отдельный target** на реальных лабораторных измерениях ЛИМС. ПАК и предыдущие лабораторные результаты могут использоваться как признаки, но не должны смешиваться с ЛИМС в одну целевую колонку.

<aside>
⚠️

На текущем этапе **не зафиксировано**, какая именно точка отбора соответствует финальному товарному дизелю для каждого target. Для окончательного выбора `y` нужны точка отбора, время отбора и желательно ID пробы.

</aside>

## Как собирать обучающую строку

Одна строка датасета соответствует одной реальной пробе ЛИМС.

```
ЛИМС-проба в момент t
        ↓
телеметрия АВТ + 24-2000 ДО t
        ↓
ПАК ДО t + age/freshness
        ↓
lag / rolling признаки
        ↓
target = лабораторное значение ЛИМС
```

### Что входит в X

- телеметрия АВТ + 24-2000;
- ПАК;
- предыдущий известный ЛИМС, если это разрешено экспериментом;
- `age / freshness` анализов;
- признаки сырья;
- lag-признаки: 30 мин / 1 ч / 2 ч / 6 ч и другие кандидаты;
- rolling-признаки: `mean / std / slope`.

### Что входит в y

Реальное лабораторное значение выбранного показателя в момент отбора пробы.

### Что запрещено

- использовать информацию после момента отбора пробы;
- делать случайный `train/test split`;
- протягивать один ЛИМС-результат на множество 10-минутных строк и считать их независимыми target-наблюдениями.

## Качество и аномалии ЛИМС

Редкое значение **не равно ошибке**. Плохой технологический режим может быть самым важным примером для модели.

| Класс | Что делаем |
| --- | --- |
| **Нормальные** | Используем для обучения и валидации |
| **Подозрительные** | Оставляем, ставим `is_anomaly = 1`, понижаем confidence |
| **Физически некорректные** | Не используем как target; сохраняем причину флага |

Пример физического правила:

```
T50 ≤ T90 ≤ T95
```

Если порядок нарушается, анализ считается подозрительным. Значение `T95 = 0` приведено как пример некорректного target. При этом `Sulfur = 14 мг/кг` нельзя удалять только потому, что оно высокое: это может быть реальный режим с нарушением качества.

Причины флагов должны логироваться, например: `range / physics / stale`.

## Что ещё нужно уточнить именно по ЛИМС

- точку отбора для каждого интересующего показателя;
- продукт, к которому относится каждая точка;
- является ли timestamp временем **отбора пробы**, а не временем регистрации результата;
- наличие и стабильность `sample_id` / ID пробы;
- единицы показателей;
- частоту и интервалы между пробами по точкам;
- дубли и повторные анализы одной пробы;
- экстремальные значения, включая серу `2120`;
- физически некорректные комбинации показателей;
- периоды изменения частоты лабораторных анализов.

## Что нужно получить на выходе исследования ЛИМС

1. **Карта точек отбора:** `точка → продукт → показатели → единицы → число проб → период наблюдений`.
2. **Таблица target-кандидатов:** Sulfur / T95 / FlashPoint / D15 с числом валидных лабораторных измерений.
3. **Разметка качества данных:** нормальный / подозрительный / некорректный + причина.
4. **Проверенный timestamp отбора** и, если доступен, ID пробы.
5. **Готовая таблица лабораторных событий**, которую можно связывать с историей телеметрии по времени.
