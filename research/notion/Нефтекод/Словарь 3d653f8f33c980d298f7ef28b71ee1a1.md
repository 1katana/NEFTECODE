# Словарь

Например, оператор меняет расход сырья. Программа оценивает, как это может повлиять на серу и нагрузку на оборудование, проверяет ограничения и отвечает: **«Можно изменить», «Лучше оставить как есть» или «Данных недостаточно»**. Именно такой понятный и обоснованный ответ должна научиться выдавать ваша команда.

**Нефть → разделение на части → очистка → смешивание → готовое дизельное топливо.**

| **Термин** | **Простыми словами** |
| --- | --- |
| **АВТ** | Установка, где нагревают нефть и разделяют её на части. Полное название — атмосферно-вакуумная трубчатая установка |
| **Фракция** | Часть нефти с определённым диапазоном температур кипения. Например, дизельная фракция — материал для получения дизеля |
| **Гидроочистка** | Очистка топлива с помощью водорода, в частности от соединений серы |
| **24-2000** | Обозначение установки гидроочистки в ваших файлах |
| **Блендинг** | Смешивание компонентов в нужных пропорциях, чтобы получить топливо требуемого качества |
| **ДТ** | Дизельное топливо |
| **ГОДТ** | Гидроочищенное дизельное топливо — дизель после очистки |
| **Товарное топливо** | Готовый продукт, который соответствует установленным требованиям |
| **Сырьё** | То, что поступает на очередной этап обработки. Это не обязательно исходная нефть |

Разделение нефти и смешивание компонентов — обычные этапы нефтепереработки.

**Показатели качества топлива в ваших таблицах означают следующее.**

| **Название в файлах** | **Простое объяснение** |
| --- | --- |
| **Mg.Sulfur, содержание серы** | Сколько миллиграммов серы содержится в килограмме топлива. По вашему ТЗ для готового дизеля — не больше **10 мг/кг** |
| **Mass.Sulfur, МД серы** | Массовая доля серы. В вашей лабораторной выгрузке Mass.Sulfur указана в процентах. Её нельзя напрямую сравнивать со значением в мг/кг |
| **D15** | Плотность топлива при 15 °C: сколько весит один кубический метр |
| **T50, 50%.T** | Температура, к которой при лабораторной перегонке отогнали половину объёма пробы |
| **T90, T95, T98** | То же самое для 90%, 95% и 98% пробы. Помогает описать состав топлива |
| **IBP.T, ТНК, начало кипения** | Температура начала перегонки — появления первых капель отогнанного продукта |
| **EBP.T, конец кипения** | Температура конца перегонки по методике испытания |
| **I250, I350, ОДИС** | Какая доля объёма пробы отгоняется до 250 или 350 °C. Здесь результат — в процентах |
| **CloudPoint, температура помутнения** | При охлаждении начинают появляться кристаллы парафинов, и топливо мутнеет |
| **CFPP, ПТФ, FilterabilityLimit.T** | Показатель того, насколько сильное охлаждение топливо выдерживает до проблем с прохождением через фильтр |
| **PourPoint, температура застывания** | Показатель потери подвижности топлива при охлаждении |
| **FlashPoint, температура вспышки** | Температура, при которой пары топлива могут вспыхнуть от источника зажигания в условиях испытания |
| **CetaneNumber, цетановое число** | Насколько легко топливо воспламеняется от сжатия в дизельном двигателе |
| **ViscosityK, кинематическая вязкость** | Насколько легко топливо течёт: условно, насколько оно «густое» |

**Обозначения вроде T6 и F26 — это имена сигналов, или теги.**

**Тег** — короткое имя конкретного измерения.

**date** — время измерения.

**Unnamed: …** — служебная нумерация строк, не показание датчика.

**Точка отбора** — место, где взяли пробу топлива.

**ЛИМС** — система хранения лабораторных анализов.

**Телеметрия** — показания датчиков, записанные во времени.

**Возраст анализа** — сколько времени прошло с измерения.

**Запаздывание** — время между изменением режима и изменением качества продукта.
