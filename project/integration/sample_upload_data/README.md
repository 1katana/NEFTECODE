# Тестовый набор для загрузки через операторскую консоль

Выберите файлы в форме в таком соответствии:

- **АВТ, CSV** → `avt_tags.csv`;
- **24-2000, CSV** → `242000_tags.csv`;
- **ЛИМС, XLSX** → `lims.xlsx`;
- **Справочник тегов, XLSX** → `tags.xlsx`;
- **ПАК/ВАК, XLSX** → `pak.xlsx`.

В CSV оставлены первые 81 десятиминутная точки реальной телеметрии за
`2023-01-01`; это даёт API 36 точек истории для модели. XLSX-файлы сохранены
без изменений, чтобы проверка прошла через тот же формат, что и основной
пайплайн. Набор предназначен только для демонстрации: результат отмечается
как `HISTORICAL` и может корректно вернуть защитный `REFUSE`.
