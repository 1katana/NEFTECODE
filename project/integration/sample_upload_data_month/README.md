# Месячный тестовый набор для операторской консоли

Период данных: **2023-01-01 00:00 — 2023-01-31 23:50** (4 464 точки с шагом
10 минут). Все файлы согласованы с формой «Загрузить свои тестовые данные»:

| Поле формы | Файл |
| --- | --- |
| АВТ, CSV | `avt_tags.csv` |
| 24-2000, CSV | `242000_tags.csv` |
| ЛИМС, XLSX | `lims.xlsx` |
| Справочник тегов, XLSX | `tags.xlsx` |
| ПАК/ВАК, XLSX | `pak.xlsx` |

Набор проходит полный маршрут `neftecode_processing.py → Integration API`.
Он помечается как исторический (`HISTORICAL`), поэтому `REFUSE` является
ожидаемым защитным ответом при отсутствии подтверждённой рецептуры смешения и
промышленных границ управлений.
