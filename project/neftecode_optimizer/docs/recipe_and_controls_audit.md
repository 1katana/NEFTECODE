# Рецептура и границы управлений: проверка источников

Проверено по материалам проекта 21 сентября 2026 года. Для решения в API
используются только явно переданные данные. Исторический случай без рецептуры
остаётся `REFUSE`; учебная смесь помечена `SYNTHETIC`.

| Источник | Что подтверждает | Чего не даёт |
| --- | --- | --- |
| `neftecode_chat/теги АВТ_24-2000.xlsx`, лист `24-2000` | `T6` — температура ГСС на входе Р-202; `F9` — массовый расход сырья; `P13` — давление на входе Р-202 | Права изменять уставки, min/max/step/max_delta |
| `neftecode_chat/формулы_ВАК.xlsx` | Формулы виртуальных анализаторов T50, T90, T95, плотности, температур помутнения и других показателей | Рецептуру смешения и причинный эффект изменения уставки |
| `neftecode_chat/Ustanovka_AVT_merged (1).pdf`, стр. 2–4 | Схему смешения очищенного дизеля, керосина и газойля; сумма долей 100%; целевые показатели товарного продукта | Числовые доли, свойства резервуаров, ограничения запасов |
| `ТЗ_нефтекод.docx` | Если рабочий диапазон не подтверждён, исторические экстремумы нельзя выдавать за промышленные пределы; экспериментальные диапазоны должны быть обозначены | Утверждённые операторские диапазоны |
| `Теги_хакатон.xlsx`, лист `КИП` | Ранний справочник | Содержит противоречащие исправленному справочнику описания `T6/F9/P13`; для этих тегов не используется |

`neftecode_optimizer/optimization/control_config.yaml` задаёт диапазоны с
`basis: EXPERIMENTAL_MODEL`: `hyd_t6` 340–385 °C, `hyd_f9` 170–270 т/ч,
`hyd_p13` 3,6–4,1 МПа, доля гидроочищенного 50–100%, доля резервуара с низкой
серой 0–50%, присадка 0–3%. Это параметры учебного поиска, **не подтверждённые
границы управления**. Последний предел присадки также фигурирует в проектных
материалах, но её реальное применение и дозирование не подтверждены.

`Quality_neftecode/configs/modeling.yaml` содержит линейные коэффициенты
candidate-модели (`T6`: −0,03 мг/кг на °C; `F9`: +0,015 мг/кг на т/ч;
`P13`: −1,5 мг/кг на МПа). Они позволяют вычислить what-if, но не доказывают
эффект действия на установке. Формулы из `формулы_ВАК.xlsx` описывают корреляции
измерений с показателями качества; часть формул включает ЛИМС, поэтому применять
их онлайн без контроля времени публикации нельзя.

Для демонстрации полного расчёта `integration/examples/illustrative_blend_20260515_1200.json`
сочетает измеренную телеметрию и ПАК с **предположенной** смесью 80/20 из
`integration/runtime/demo_request.json`. Происхождение полей записано рядом в
`_evidence.json`. Успешный `KEEP` этого сценария показывает прохождение блоков
системы, а не готовность менять управление на объекте.

Перед операторским `RECOMMEND` нужны утверждённые границы и шаги уставок,
фактический состав компонентов и запасы, проверенная динамика кандидата и
экспертная проверка оценок надёжности.
